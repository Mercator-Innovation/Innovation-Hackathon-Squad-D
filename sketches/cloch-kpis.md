# Cloch Housing Association's KPIs

Found by Faye. These are the Scottish Housing Regulator's standard published indicators — the same measures every Scottish social landlord reports, so they're a fair comparison (Scottish average shown alongside).

Source: [Scottish Housing Regulator — Cloch Housing Association Ltd landlord page](https://www.housingregulator.gov.scot/landlord-performance/landlords/cloch-housing-association-ltd/)

| Indicator | Cloch | Scottish average |
|---|---|---|
| **Satisfaction** | | |
| Overall service satisfaction | 93.0% | 87.6% |
| Kept informed about services and outcomes | 99.7% | 91.4% |
| Satisfied with opportunities to participate | 99.0% | 88.1% |
| **Quality and maintenance** | | |
| Homes meeting the Scottish Housing Quality Standard | 94.0% | 89.5% |
| Average time for emergency repairs | 2.4 hours | 3.5 hours |
| Average time for non-emergency repairs | 5.5 days | 8.8 days |
| Reactive repairs completed right first time | 96.2% | 95.3% |
| Satisfied with repairs or maintenance | 86.8% | 88.1% (the one measure Cloch is slightly below average on) |
| **Neighbourhoods** | | |
| Anti-social behaviour cases resolved | 97.8% | 93.1% |
| **Value for money** | | |
| Rent collected (current and past rent, as % of rent due) | 99.9% | 99.7% |
| Rent not collected due to empty homes | 0.3% | 1.1% |
| Average time to re-let homes | 17.7 days | 51.7 days |

**Other figures (no Scottish comparison given):**
- Homes owned at 31 March 2026: 1,446
- Total rent due for the year: £8,614,395
- Average weekly rent increase: 4.8%
- Debt per unit: £9,890

**Not published on the regulator's page:** complaints figures, EESSH/energy-efficiency compliance, rent arrears as a standalone measure.

**For the challenge:** Cloch outperforms the Scottish average on nearly every measure — this isn't a struggling landlord, just one without the data to catch damp/mould problems early. Worth keeping in mind so the prototype doesn't assume Cloch is under-resourced generally, just data-poor on this specific problem.
